I have been solving Rubik's cubes since 2012, and average under 10 seconds using the Roux method (my <a href='https://www.worldcubeassociation.org/persons/2016PETE11'>WCA Profile</a> for those interested).

Besides competing, I participate in the cubing community in a few different ways. I built and maintain <a href='https://rouxcubing.com/'>RouxCubing.com</a>, a website with tutorials and resources for solving using the Roux method. Since 2023 I have also been managing the Roux Weekly Competition, a casual online competition that has been running since 2014.
